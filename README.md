Secure Coding Review

Project Overview

This project demonstrates secure coding practices by reviewing a login system and identifying common security weaknesses. It focuses on improving authentication security and handling invalid login attempts safely.

Objectives

- Understand common security vulnerabilities.
- Validate user login credentials.
- Display safe error messages for invalid login attempts.
- Apply secure coding principles.
- Test the application with valid and invalid inputs.

Features

- Login authentication testing.
- Invalid login handling.
- Generic error message: "Invalid username or password."
- Basic security improvements.
- Testing of login functionality.

Technologies Used

- Python
- Visual Studio Code
- Git and GitHub

Testing

The application was tested using incorrect login credentials. The system displayed the message:

"Invalid username or password."

This helps avoid revealing whether a particular username or password is incorrect.

Key Learnings

- Importance of secure authentication.
- Safe handling of login errors.
- Basic input validation and testing.
- Secure coding practices.
- Using GitHub to manage and document a project.
